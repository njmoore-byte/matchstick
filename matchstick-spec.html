Application Rules

How the palette behaves

Accent restraintRule 01

Accent red should occupy no more than 3–5% of any spread. Apply to: eyebrow labels, drop caps, italic emphasis inside headlines, the 4px tab above pull quotes and Bottom Line panels, italic letterforms inside marks. Never use accent for body copy.

Sulfur is specialRule 02

Sulfur appears in exactly two contexts: as a highlighter band behind a short phrase of body copy (use sparingly — one or two phrases per issue), and as the label text colour on the Bottom Line panel. Do not use it anywhere else.

Ink hierarchyRule 03

Three weights of ink — full, soft, muted — map to three semantic levels. Ink for primary information, ink-soft for editorial colour (decks, captions where they matter), ink-muted for utility (bylines, footers, image captions).

Rules and dividersRule 04

Two divider weights exist: 1.5px in full ink (section heads, top of pull quote, masthead) and 0.5px in the rule colour (column dividers, deck underline, footer top). Don't introduce additional weights.

iii.

Page setup.

The Matchstick is a single A4 sheet printed both sides. Each page uses a two-column body grid framed by generous outer margins and a consistent top-and-tail furniture.

Page geometry

The frame

FormatA4

210 × 297mm · portrait · single sheet, two-sided. No bleed required for internal print runs; add 3mm if professionally printed.

MarginsPage

Top: 16mm · Sides: 18mm · Bottom: 14mm. The footer sits at 9mm from the bottom edge, outside the body area.

Body gridColumns

Two-column body, equal width. Column gap: 24px. Divider: 0.5px rule colour, running the full body height between columns.

Section 05 · Rules & handover
v.

Rules & edge cases.

Recurring decisions that come up across issues. Apply consistently; deviations should be deliberate, not accidental.

Editorial defaults

Tone of voice for the page

CasingRule

Sentence case throughout, including headlines and section heads. ALL CAPS appears only in Archivo Narrow utility text (eyebrows, labels, bylines, footer, captions). Never set body or display in caps.

Italic emphasisRule

Italic is the workhorse for emphasis — in body, deck, headlines (where italic words also take the accent colour). Avoid bold inside body copy. Where an entity name needs setting apart (a song title, a brand), use italic, not quotes.

NumeralsRule

EB Garamond and Fraunces both offer old-style figures. Use them — they sit better in justified body. Tabular figures only in data tables (rare in this format).

HyphenationRule

Body is justified with auto-hyphenation enabled. Avoid more than two consecutive hyphenated line ends. Manual hyphenation overrides are fine — protect proper nouns from breaking.

Imagery & figures

Working with photography

TreatmentImage

Imagery should feel reportorial, not promotional — duotone-treated black-and-white or warm sepia preferred over full colour. Slot inside a single column or span both. Always pair with a caption.

CaptionImage

Archivo Narrow 9.5px UPPERCASE, ink-muted, looser tracking (+0.06em vs +0.18em elsewhere). Sits flush below the image with 0 top margin. Start with "Figure 01 ·" or similar, then a brief description.

Figma file structure

How to organise the file

Recommended pagesFile

① Cover / styles — published colour styles, text styles, effect styles
② Components — every reusable module from Section 04, as components with variants
③ Templates — two A4 frames (page 1, page 2) with components placed and dummy copy
④ Issue 24 — duplicated template with this issue's live content
Each subsequent issue duplicates page ④ and renames it. The template stays untouched.

Component variants worth buildingFile

Masthead — Front / Continued variants
Section head — Standard / What-this-means (numbered)
Pull quote — Short / Long (auto-grows with text)
Image block — Single column / Spanning columns
Build the Bottom Line panel and Sign-off as single-instance components; they appear once per issue.

Questions while building

Open both the reference HTML and this specification side by side. Where they conflict, the HTML wins — it's the rendered source of truth. Once the Figma file is built, this document becomes the brief for issues 25 onward, where the designer's job is content placement, not system decisions.
